## Registers & bands

- Typed answers are decimal NUMBERS via `answerType: "decimal"` (the
  `fractionalAnswer` QC check exempts /decimal|fraction/ modes); fraction
  labels are strings ("7/10"); comparisons use choice `<`/`>`/`=` — never
  symbolSelect/numberLine/multiSelect.
- Bands: K-1 tenths only (0.1–0.9); 2-3 tenths + hundredths (< 1); 4-5
  hundredths with whole parts (to 9.99).
- **Letter-free drill forms are load-bearing**: `isVerbalPrompt` counts ≥6
  total letters, and sessions default to word-problems OFF, so each
  procedural band carries letter-free items the filter can serve —
  `0.2 + 0.1 = ?`, `0.4, 0.5, 0.6, ?`, `0.3 ? 0.7`, `7/10 = ?`, and the
  numerator fills `0.7 = ?/10` / `?/100 = 0.45`. Verified in-session:
  words-off level-1 procedural 60/60 bank-served.
- Band-1 magnitude rule treats decimals by their whole part ("0.30" is not
  a 30 — the authoring throw strips fractional digits first), but the QC
  `bandAppropriate` check does NOT, so band-1 avoids "0.X0" strings beyond
  0.10/0.20 and never states hundredths.

Misconception traps: writing tenths into the hundredths place (0.07 for
seven tenths), longer-decimal-is-bigger (0.18 > 0.6), trailing-zero
value change (0.40 beats 0.4), whole-number digit comparison.
