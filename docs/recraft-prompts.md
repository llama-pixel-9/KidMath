# Recraft Prompts — short versions (fit the prompt character limit)

One prompt per bird, each under 1,000 characters, ready to paste. Rarity tier is in
each title (Common 15–25⭐ · Uncommon 40–60⭐ · Rare 90–125⭐ · Legendary egg-only) —
legendaries and their chicks deserve the most generation attempts; they're the
ceiling of the collection. Same workflow: pilot 4 → lock a custom style
("+ Create style", top-right of the Style dialog) → batch the rest.
Export SVG → `design/meadow-art-pilot/generated/<speciesId>.svg`.
