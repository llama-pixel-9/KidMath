## Visual payloads (mirror the generator exactly)

- bar graph: `display {type:"barGraph", figure:"barGraph",
  bars:[{label,value}×4]}` + `answerType:"barGraph"`, four DISTINCT values.
- tally: `display {figure:"tallyChart", rows:[{label,count}]}`.
- pictograph: `display {figure:"pictograph", keyValue, rows:[{label,
  symbols}]}`.

Bands scale the data: K-1 values ≤9 (bar totals ≤20 so judged-total prompts
stay under the band-1 gate), key-1 pictographs; 2-3 values ≤14, keys 2/5;
4-5 values ≤20, key 10.

## The uniqueness discipline (this mode's trap)

Graph prompts carry almost no numbers, so promptText uniqueness must come
from WORDS: every prompt embeds the graph's title (six category sets:
pet fair / fruit stand / recess games / favorite colors / bird watch /
school ride), each band has its OWN phrasing set, repeated set-uses within
a band switch phrasing by pass, and names carry non-congruent per-band
offsets (0/7/13 — offsets ≡ 0 mod 20 collide names ACROSS bands, and
number-free story skeletons need three variants PER BAND).
