## Band magnitudes

| Band | Coins | Amounts |
|---|---|---|
| K-1 | pennies, nickels, dimes only | everything stated ≤20¢ |
| 2-3 | quarters join | to ~$1 |
| 4-5 | dollar notation | to ~$5 |

**A quarter's value (25) may never be STATED in a band-1 prompt** — the
bandAppropriate gate hard-fails band-1 prompts with numbers >20. Band-1
change/save-up problems work from 10/15/20-cent targets.

## Registers

- Coin-sum drills: "1 dime, 1 nickel and 4 pennies = ? cents".
- Visual trays: letter-free values caption ("10 + 5 + 1 = ? c" — globally
  unique per coin multiset, distinct from addition's "a + b = ?" via the
  " c" suffix and from disc captions via the "+"), with `answerType:
  "coinTray"` + `display.{coins, coinMode:"count"}`.
- Change: "Pay 25 cents for a 18-cent toy. Change = ? cents" (countBack
  claim). Save-up: "18 cents saved. ? more cents make 25 cents" (gap).
- Trades: "1 quarter = ? nickels" / "? nickels make 25 cents".
- Fewest coins: "Fewest coins for 87 cents = ?" (greedy, optimal for US
  denominations).
- Judged = "Is this right?" Yes/No + `display.truth`. Story contexts:
  prize booth / lemonade stand / book sale / craft table, coin machine,
  trading post.

## Verification

countMath claims: `sum` (coin values as parts), `countBack` (change,
spending), `gap` (save-up), `moreLess` (earn a coin). `display.money`
claims re-derived by `authorMoney.js`: coinValue, countVsValue (the
count-the-coins-not-the-value slip), trade, fewest, eq, compare, afford,
anyChange, changeSaid, notation, notationPick. Tray items additionally
assert the drawn coins sum to the answer.
